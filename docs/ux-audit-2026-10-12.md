# Keeps PWA: UI/UX and functional audit — 12 October 2026

Scope: the Keeps PWA (keeps.web.app, repo at `6364358`) on iOS Safari standalone and Android Chrome, plus the backend summarization pipeline. Method: four independent read-only agents (frontend PWA code, core flows / offline / error handling, backend AI quality with production sampling, live browser test), spot-verified by the orchestrator. Backend test suite: 497 passed, 16 skipped. Frontend `tsc` clean. No project files or production data were changed.

**Platform caveat.** The live test could only reach the signed-out shell because production is currently blank (see 0.1). Touch-target measurement, layout at 320/360/375 px, ingest timing, invalid-URL copy, search and delete were therefore audited from code, not on a device. iOS-only behaviours (popup sign-in in standalone, keyboard overlap, long-press callout) are marked "needs device verification". Re-run the live pass after 0.1 is fixed.

Detailed agent reports (with full evidence) sit in the session scratchpad: `audit-frontend-pwa.md`, `audit-flows-offline-errors.md`, `audit-ai-quality.md`, `audit-live-browser.md`.

## 3. UX optimization recommendations (native-feel, ranked by impact ÷ effort)

1. **Restore production and fail the build on missing config** (0.1). Everything else is moot until the app boots.
2. **Offline app shell in the service worker** (1.1). One fetch-handler branch makes the installed app open offline, routes offline Android shares into the existing queue, and unlocks the Firestore cache already in place.
3. **44 px chips and toast dismiss** (1.4, 2.12). Two CSS lines on the most-tapped controls.
4. **Human error copy end to end** (1.2, 2.17, 2.19, 2.20, 2.27, 3.16, 3.17). A single `jobErrorMessage` map plus reason-specific degraded banners removes every raw code and misleading "Caption only" the user can currently see.
5. **Native sheet motion** (2.5) and **keyboard-aware sheets** (2.6). Slide-up entrance, animated exit on every close path, `interactive-widget` / `visualViewport` sizing.
6. **Edge-to-edge on iOS done safely** (2.1). `viewport-fit=cover` plus status-bar meta plus top insets on every route, in one change.
7. **Fix swipe-back** (2.2, 2.3, 3.1). iOS-only gating, dimmed underlay, edge-zone-only listener.
8. **Real skeletons and action feedback** (2.7, 2.11). Content-shaped skeletons; "Saved" / "Deleted" toasts.
9. **Recovery paths** (2.4, 2.13, 2.14, 2.16, 2.9). Retry that re-subscribes the feed; stale `processing` handled like stale `pending`; Retry re-dispatches instead of duplicating; update check on `visibilitychange` with a "New version" toast instead of a surprise reload.
10. **Category-coloured thumbnail fallback + persisted cover thumb** (1.8, 0.2). Keeps the feed scannable when CDNs expire.
11. **Show timestamps** (2.23). The main "jump back into the video" affordance already exists in the data.
12. **Install prompt lifecycle and manifest polish** (2.8, 3.5). Clear the deferred prompt, listen for `appinstalled`, add `id`/`scope`/`shortcuts`, media-keyed theme-color.
